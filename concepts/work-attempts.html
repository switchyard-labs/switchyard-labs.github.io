Concepts · Work, Attempts & Pull Requests

Intent, isolation, and a pull request.

Work is the intent. An Attempt is an isolated branch where the change is built. A Pull Request is how it offers itself for review.

Work

A Work item is a recorded intent — a feature, fix, or task — with an owner and a status. It is the root of the provenance chain.

Attempts

An Attempt opens an isolated branch (for example attempt-<id>) with a marker file. Agents and humans work there in complete isolation:

  • the attempt branch is the only place an agent can write;
  • every agent run is an execution record (role, adapter, status, output);
  • draft edits in the editor are saved to an ephemeral draft and committed explicitly through the same ref substrate.

Pull Requests

A PR proposes an attempt branch against a base. It carries a deterministic check, structured review findings, and — critically — a preview of whether it will integrate. Then it enters the Integration Queue.
