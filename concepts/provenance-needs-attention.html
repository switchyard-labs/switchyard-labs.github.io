Concepts · Provenance & Needs Attention

Explainable changes. Surfaceable decisions.

Every canonical change has a full chain. Everything that needs a human is in one place, with the information to decide.

Provenance

Work → Attempt → runs → PR → ref updates → normalized events: a durable, queryable chain for any change. Nothing on canonical is anonymous.

Needs Attention

One list aggregates everything that needs a decision:

  • attempts parked in conflict;
  • blocked integration-queue items;
  • workflow runs waiting for approval;
  • open error findings.

Escalation decision packets

When a change is blocked, it can be escalated into a self-contained decision packet: target, repository, branch, base, the conflicting files with base and source versions, the findings, and the suggested resolutions. You decide without reconstructing history.

DecisionEffect
take_oursCanonical's version wins; the attempt resolves and can be re-queued.
take_theirsThe attempt's version is kept (recorded).
three_wayA real three-way merge resolves the files.
approveUnblocks a workflow waiting for approval.
requeueRe-runs a blocked integration item.
