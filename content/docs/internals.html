The dual-path event identity

The event fast path and reconciliation both write normalized domain events keyed by the transition identity (repo, ref, before, after) — deliberately free of delivery metadata (message id, seen time). Both paths converge on one durable domain event and one broadcast. Trestle's Idempotency-Key returns replayed=true only for byte-identical content; the same identity with different metadata yields 409 idempotency_conflict, which Switchyard treats as convergence (the fact already exists once) and acknowledges — no retry churn, no duplicate broadcast.

Queue mechanics

  • Cloudflare queue message bodies arrive as JSON-encoded strings; the consumer decodes the string, then the envelope.
  • Pull + ack semantics with visibility timeouts give at-least-once delivery.
  • Failed ingests are returned to the queue (retried), not acked.

Credential store

  • AES-256-GCM ciphertext at rest; metadata-only API; plaintext only during execution resolution (scoped 0600 file).
  • Key from SWITCHYARD_SECRET_KEY or data/secret.key.
  • Threat model: co-located key ⇒ protects against database-only compromise, not full host compromise.
