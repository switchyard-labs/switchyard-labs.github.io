Build and run the control plane.

A Go binary, a Trestle, an Artifacts namespace, and a token helper. That's the whole platform.

Prerequisites

  • A Cloudflare account on the Workers Paid plan (Artifacts is Paid-only).
  • Artifacts access with artifacts.read + artifacts.write scopes.
  • A token helper — a script that prints a fresh account token (the control plane never holds a static credential).
  • A Trestle instance with an admin user/password.
  • Go 1.22+, git, and the Strut worker binary (deterministic adapter).

Build & run

go build -o switchyard ./cmd/switchyard

# configure via environment (see Configuration) then:
set -a; source cp0.env; set +a
./switchyard

On startup the control plane provisions its Trestle collections and starts the reconciler, the optional queue consumer, the workflow runner, and the integration-queue worker, then serves the app.
