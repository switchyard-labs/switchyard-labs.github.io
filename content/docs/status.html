What is proven, what is conditional, what is next.

Switchyard has moved well beyond the original CP13 prototype: the Git-host product layer, profiles/organisations, Warden-style editor workbench, Pull Requests, settings and read-only demo model now exist. This page distinguishes implemented capability from the remaining live/release certification work.

PASS

Editor concurrency

Draft revision CAS, Agent-vs-human stale protection and external branch movement detection.

PASS

Conflict honesty

Textual merge conflicts and deterministic repair plus semantic conflicts where Git merges cleanly but a repository contract fails.

Still conditional

Real provider-backed coding AgentThe runner abstraction and coding-agent adapter path exist, but the original campaign did not execute a real provider-backed coding Agent on the control-plane host. The deterministic adapter certified the substrate. Closing this condition requires a suitable CLI/provider credential and one meaningful end-to-end Agent task.
Cloudflare pushed-event source legThe Queue→Switchyard→Trestle→SSE fast path is implemented and tested, and CP0 previously proved Artifacts event delivery. During later certification the upstream Artifacts event-subscription→Queue delivery stopped flowing account-wide, so reconciliation remains the correctness safety net until that source leg is re-certified.
