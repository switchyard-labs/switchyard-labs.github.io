Concepts · Architecture

Two truths, one substrate.

Git is the truth for content. A coordination store is the truth for state. The control plane is the only place that can move canonical.

The layers

Presentation

Nift-built static app

Dark UI served directly by the control plane; a CodeMirror editor; SSE realtime.

Control plane

One Go binary

API, ref substrate, event consumer, reconciler, workflow runner, queue worker, policy engine.

Coordination

Trestle

HTTP record store: idempotent writes, If-Match CAS, strict schema. All coordination state.

Git truth

Cloudflare Artifacts

A real Git server. Objects/refs are exactly what git wrote.

Execution

Strut / deterministic worker

Bounded executor behind the runner adapter; a coding-agent CLI adapter is wired.

The ref substrate

Every canonical mutation goes through Update(repo, ref, expected, changes, message, provenance): read the current SHA, build a commit, push non-force — Git itself rejects stale writers. Force-push is policy-gated and never used by the integration path. Agents never hold a canonical-write credential.

Events: fast path + safety net

External Git movement is observed twice. The fast path pulls cf.artifacts.repo.pushed events from a Cloudflare Queue. The safety net periodically reconciles with git ls-remote. Both feed one idempotent ingest keyed by the transition identity, so the same movement converges to one domain event and one broadcast. Events accelerate convergence; reconciliation guarantees it.

Upstream note Cloudflare's event-subscription → Queue delivery for pushed events is currently not flowing account-wide (it was proven in CP0). The fast path is implemented and gated from the Queue onward; reconciliation covers correctness meanwhile.
