Agent-native Git collaboration

Git collaboration built for humans and concurrent agents.

Agents and people work in parallel on isolated Git branches. Canonical only moves through a deterministic, policy-controlled Integration Queue — no last-writer-wins, no force-push, no lost work.

01Git stays Git

Switchyard is ordinary Git hosting first. Nothing about the repository is a copy or a façade:

Git truth

Normal commits, branches, PRs

Repositories live on a real Git server. Your history and diffs are real Git history and diffs.

Git truth

clone / fetch / push

Ordinary git clients work unchanged, with short-lived repo-scoped tokens.

Isolation

Agents cannot reach canonical

Agents hold scoped tokens for their attempt branch only. Canonical moves only through the queue.

Concurrency

No last-writer-wins

Ref mutations are compare-and-swap; stale writers are rejected by Git itself.

02Humans and agents

The same loop serves both. Humans use the browser editor and ordinary Git; agents use a durable, programmable workflow substrate. Both converge on the Integration Queue, and every canonical change is attributable.

Humans

Editor with draft CAS

CodeMirror editing, Save ≠ Commit, stale-save rejection, diff, findings, Agent panel.

Agents

Roles + scoped credentials

Implementer / reviewer / conflict-resolver with explicit capabilities; secrets resolve only at execution.

Agents

Durable workflows

JS-authored steps that survive process death; completed steps replay, never re-execute.

Oversight

Needs Attention

Conflicts, blocked integrations and approval gates surface in one list — with self-contained decision packets.

03A durable, programmable workflow

function run(ctx) {
  await ctx.agent({ repo, branch, file, append });
  await ctx.check({ repo, branch });
  await ctx.review({ repo, branch });
  await ctx.wait_approval({ reason: "merge to main" });
  await ctx.integrate({ repo, branch, base: "main" });
}

Every Switchyard operation is a durable step. Executor dies mid-run? The workflow resumes, replays what it already did, and never duplicates an external effect.
