Docs · API

The HTTP surface.

One authenticated JSON API. Sessions via bcrypt + HttpOnly cookies; refs, work, attempts, PRs, the queue, workflows, policy, and the editor.

AreaEndpoints

Work / Attempts / PRs/api/work… · /api/attempts/{id}/run|review|preview|resolve · /api/prs/{id}/check|integrate|enqueue

Agents / credentials/api/credentials… · GET /api/roles

Notable semantics

  • Draft CAS: saves carry expected_revision; a stale save returns 409 draft_stale. Commits compare base_sha to the current head and return 409 stale_base on external movement.
  • Queue: POST /api/prs/{id}/enqueue enqueues; the worker integrates strictly FIFO under policy; blocked items expose preview_conflict or semantic_conflict.
  • Realtime: authenticated SSE at /api/events/stream delivers normalized domain events.
