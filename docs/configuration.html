Environment variables.

The control plane is configured entirely through environment variables — one process, no config files.

VariablePurpose
SWITCHYARD_TRESTLE_URLTrestle base URL (default http://127.0.0.1:7350).
SWITCHYARD_TRESTLE_USER / SWITCHYARD_TRESTLE_PASSTrestle admin credentials (required).
SWITCHYARD_ARTIFACTS_ACCOUNTCloudflare account id (required).
SWITCHYARD_ARTIFACTS_NAMESPACEArtifacts namespace.
SWITCHYARD_ARTIFACTS_TOKEN_CMDToken helper path.
SWITCHYARD_STATIC_DIRBuilt web app directory.
SWITCHYARD_LISTENListen address (default 127.0.0.1:8080).
SWITCHYARD_DATA_DIRData dir (scratch clones, secret key).
SWITCHYARD_STRUT_BINStrut worker binary.
SWITCHYARD_RECONCILE_INTERVALReconciliation period (default 15s).
SWITCHYARD_QUEUE_IDCloudflare Queue id for the event fast path (optional).
SWITCHYARD_QUEUE_PULL_INTERVALQueue pull period (default 5s).
SWITCHYARD_WORKFLOW_INTERVALWorkflow runner period (default 2s).
SWITCHYARD_QUEUE_INTEGRATE_INTERVALIntegration queue worker period (default 3s).
SWITCHYARD_SECRET_KEYOptional 32-byte key for credential encryption; otherwise persisted to data/secret.key.

Example

SWITCHYARD_TRESTLE_URL=http://127.0.0.1:7350
SWITCHYARD_TRESTLE_USER=admin
SWITCHYARD_TRESTLE_PASS=CHANGE_ME
SWITCHYARD_ARTIFACTS_ACCOUNT=YOUR_ACCOUNT_ID
SWITCHYARD_ARTIFACTS_NAMESPACE=switchyard-cp0
SWITCHYARD_ARTIFACTS_TOKEN_CMD=/opt/switchyard/token.sh
SWITCHYARD_STATIC_DIR=/opt/switchyard/public
SWITCHYARD_LISTEN=127.0.0.1:8080
SWITCHYARD_DATA_DIR=/opt/switchyard/data
SWITCHYARD_STRUT_BIN=/opt/switchyard/deterministic-worker
SWITCHYARD_RECONCILE_INTERVAL=15s
SWITCHYARD_QUEUE_ID=YOUR_QUEUE_ID          # optional
SWITCHYARD_QUEUE_PULL_INTERVAL=5s
SWITCHYARD_WORKFLOW_INTERVAL=2s
SWITCHYARD_QUEUE_INTEGRATE_INTERVAL=3s
