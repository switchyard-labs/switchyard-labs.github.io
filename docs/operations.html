Docs · Operations

Running it, reliably.

Idempotent provisioning, restart safety, and the operational notes that matter for a self-hosted control plane.

Restart safety

  • Provisioning is idempotent; restarting the process is safe.
  • Reconciliation + durable records mean nothing important lives only in memory.
  • Workflow runs resume after process death (durable steps replay).
  • Queue items survive restart (strict FIFO with an in-flight guard).

Credentials

Provider credentials are encrypted at rest (AES-256-GCM). The key is read from SWITCHYARD_SECRET_KEY or persisted to data/secret.key. Honest threat model: a co-located key protects against database-only / accidental disclosure, not full host compromise. Back up data/secret.key together with the Trestle records to restore the store.

Backup & recovery

Git truth lives in Artifacts; coordination state lives in Trestle. A restore is: restore Trestle records + the secret key + (optionally) the Cloudflare namespace. Full backup/restore tooling and disaster recovery are hardening items.

Observability

The control plane logs startup, reconciliation, queue, workflow, and integration activity. Prometheus-style metrics, structured logs, and alerting are hardening items.
