Bounded conditions (not failures)

Real coding-agent leg The runner adapter for a real provider-backed coding-agent CLI is implemented and wired, but has not yet executed a real LLM edit. It requires a provider credential and a coding-agent CLI on the control-plane host. The deterministic adapter runs on the identical substrate.
Upstream event delivery Cloudflare's event-subscription → Queue delivery for pushed events was proven in CP0 but is currently not flowing account-wide. The Switchyard fast path is implemented and gated from the Queue onward; reconciliation covers correctness. Re-certified when the upstream leg resumes.
