Product · Human + AI collaboration

One pipeline, two ways to drive it.

Humans get ordinary Git and a careful editor. Agents get roles, scoped credentials, and a durable workflow substrate. They converge on the same Integration Queue.

For humans

Git

Nothing to relearn

git clone / fetch / push work unchanged. Branches, PRs and history are real Git.

Editor

Save ≠ Commit

A durable draft survives reload; only an explicit Commit changes the repository.

Concurrency

Draft CAS

A stale save is rejected, never silently overwritten. If the branch moved, you get reconcile guidance.

Oversight

Needs Attention

Conflicts, blocked integrations and approvals in one list, with self-contained decision packets.

For agents

Roles

Explicit capabilities

Implementer, reviewer, conflict-resolver. A provider secret never grants Switchyard authority.

Credentials

Scoped and encrypted

Encrypted at rest; plaintext only at execution resolution; metadata-only API.

Workflows

Durable by design

JS steps that survive crashes; external effects never duplicated.

Autonomy

Policy-bounded

Org policies gate file writes, budgets and integration risk — audited end to end.

The editor + agent boundary (honest)

The Agent panel in the editor runs the formal Attempt path: it executes the implementer against the attempt branch and refreshes the committed state. That is legitimate autonomous execution with its own provenance.

The interactive draft-assistance flow — you ask the Agent to edit your draft, it proposes a change at your revision, you inspect the diff, then you commit — is a targeted product task for the next milestone. The draft revision/CAS machinery it builds on already exists and is proven.

Guarantee Neither mode can overwrite your work: ref mutations are compare-and-swap, and draft saves reject stale revisions.
