Durability

The workflow substrate is replay-from-top. A workflow is a JS function calling Switchyard operations; each operation is a durable step keyed by (run_id, step_key, args_hash). If the control plane dies mid-run:

  • completed steps replay their recorded result instead of re-executing;
  • the in-flight step retries (at-least-once);
  • later steps run exactly once;
  • no external effect is duplicated.

This was proven by killing the control plane during a running durable step and observing a completed agent step replay with attempts=1 and exactly the right number of executions.

Realtime

External git pushes are observed two ways: an event fast path (Cloudflare Queue → Switchyard consumer) and a reconciliation safety net. Both feed the same idempotent ingest, keyed by the transition identity (repo, ref, before, after), so the same movement converges to one domain event. Browsers see it live over SSE.
